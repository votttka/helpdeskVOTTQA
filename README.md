# HelpDesk Prototype

Интерактивный прототип desktop-интерфейса службы поддержки в светлом aerodesign-стиле (референсы: Zendesk, Jira Service Management, Intercom, Linear).

> ⚠️ Это **фронтенд-прототип без backend**. Все данные хранятся в `localStorage` браузера. Никаких реальных API, авторизации и инфраструктуры.

## 🚀 Быстрый старт

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`.

## 📦 Сборка

```bash
npm run build
```

Готовый сайт появится в папке `dist/`.

## 🌐 Публикация в интернет (получить ссылку)

Есть несколько вариантов — от самого простого к более гибкому:

### Вариант 1. Vercel (рекомендуется, 2 минуты)

1. Залейте код в GitHub-репозиторий (см. раздел ниже).
2. Зайдите на [vercel.com](https://vercel.com) → войдите через GitHub.
3. Нажмите **Add New → Project** → выберите ваш репозиторий.
4. Vercel сам определит Vite и задеплоит. Готовая ссылка вида `https://helpdesk-xxx.vercel.app` появится автоматически.
5. При каждом `git push` — автодеплой.

### Вариант 2. Netlify (аналогично)

1. Залейте в GitHub.
2. На [netlify.com](https://netlify.com) → **Add new site → Import an existing project** → выберите репозиторий.
3. Build command: `npm run build`, Publish directory: `dist`.
4. Получите ссылку вида `https://xxx.netlify.app`.

### Вариант 3. GitHub Pages

1. Откройте `vite.config.js` и добавьте `base: '/<имя-репозитория>/'`:
   ```js
   export default defineConfig({
     base: '/helpdesk-prototype/',
     // ...
   })
   ```
2. Задеплойте:
   ```bash
   npm run build
   npx gh-pages -d dist
   ```
3. Ссылка: `https://<ваш-логин>.github.io/<имя-репозитория>/`.

### Вариант 4. Cloudflare Pages

Аналогично Vercel/Netlify — подключаете GitHub, указываете `npm run build` и `dist`.

## 🎨 Что внутри

- **Дашборд** — KPI-карточки, графики динамики и распределения по статусам, таблица «Требуют внимания».
- **Список заявок** — фильтры, мульти-выбор статусов, SLA-бейджи, контекстное меню, пагинация.
- **Карточка заявки** — вкладки «Обзор / Взаимодействия / Аудит-лог / Связанные», правая панель с SLA, исполнителем, автоматикой и интеграциями.
- **Модальные окна** — смена статуса (с динамическими полями под каждый переход), передача заявки.
- **Drawer «Новая заявка»** — создание заявки с валидацией.
- **Настройки** — 7 вкладок: статусы, матрица переходов, автоматика, SLA, воронки, роли, интеграции.
- **Роли** — 7 ролей с разными правами (оператор, инженер, классификатор, супервизор, лид, админ, аудитор). Переключатель в топбаре.
- **Автоматика** — таймеры SLA обновляются каждые 5 секунд, автопереходы из «Ждём ответа» и возврат с паузы работают на frontend-движке.
- **Уведомления** — колокольчик с счётчиком, dropdown со списком.
- **Глобальный поиск** — по номеру, теме, клиенту.

## 🧩 Технологии

- React 18 + TypeScript
- Vite 6
- Tailwind CSS 4
- React Router 6 (HashRouter — работает на любом хостинге)
- Recharts (графики)
- Lucide (иконки)
- localStorage (всё хранение данных)

## 🔒 Данные

Все данные живут только в браузере. При первом запуске генерируются 25–30 синтетических заявок с разными статусами, SLA-ситуациями и взаимодействиями. Кнопка **«Сбросить демо-данные»** в сайдбаре или меню аватара возвращает всё к начальному состоянию.

Используются только вымышленные клиенты: ООО «Ромашка», АО «Технопарк», ИП Иванов И.И., ГУП «Городские системы». Никаких реальных ФИО, телефонов, ИНН и внешних интеграций.
